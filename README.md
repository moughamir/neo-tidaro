# Neo-Tidaro Workspace

This is the root of the Neo-Tidaro monorepo, managed with Melos.

## Packages

- `apps/`: Contains the Tidaro applications (Tidaro, Tidaro Mini, and Tidash).
- `packages/`: Contains the shared packages used by the applications.
- `example/`: Contains example applications.

## Getting Started

1. Install Melos: `dart pub global activate melos`
2. Bootstrap the workspace: `melos bootstrap`
3. Run an application: `melos run run:tidaro:linux`
