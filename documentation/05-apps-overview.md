
# Apps Overview

This document provides an overview of the applications in the Tidaro workspace. For a more detailed overview of a specific application, please refer to the `README.md` file in the application's directory.

## `tidaro`

The `tidaro` app is the main mobile application for the Tidaro platform. It is a Flutter application that is available for iOS and Android. The `tidaro` app is built using the packages in the `packages/` directory.

## `tidaro_mini`

The `tidaro_mini` app is a miniature version of the Tidaro app. It is a Flutter application that is available for iOS and Android. The `tidaro_mini` app is built using the packages in the `packages/` directory.

## `tidash`

The `tidash` app is a dashboard for the Tidaro platform. It is a Flutter web application that is used to manage the platform. The `tidash` app is built using the packages in the `packages/` directory.
