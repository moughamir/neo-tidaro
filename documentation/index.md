
# Tidaro Workspace Documentation

Welcome to the official documentation for the Tidaro workspace. This documentation serves as a comprehensive guide for developers, contributors, and anyone interested in the project.

## Project Overview

Tidaro is a housekeeping and service mediation platform designed for Morocco and scalable to global markets. The application is mobile-first, with a strong emphasis on multi-language accessibility (Arabic, Tifinagh, Berber Latin, English, French).

This repository is a multi-package Flutter/Dart monorepo managed with Melos. It enables modular development where apps, features, and core libraries coexist in a unified workspace.

## Getting Started

To get started with the Tidaro workspace, you'll need to have the following installed:

- Flutter SDK (latest stable)
- Dart SDK (latest stable)
- Melos

Once you have the prerequisites installed, you can bootstrap the workspace by running the following command in the root of the repository:

```bash
melos bootstrap
```
