
# Tidaro Workspace Documentation

This directory contains the official documentation for the Tidaro workspace. The documentation is written in Markdown and is designed to be viewed in Obsidian or any other Markdown viewer.

## Structure

The documentation is organized into the following files:

- `index.md`: The main landing page for the documentation.
- `01-workspace-structure.md`: A detailed overview of the workspace structure.
- `02-coding-conventions.md`: The coding conventions and style guide for the project.
- `03-development-workflow.md`: The development and testing workflow.
- `04-packages-overview.md`: An overview of the packages in the workspace.
- `05-apps-overview.md`: An overview of the applications in the workspace.
