
# Packages Overview

This document provides an overview of the packages in the Tidaro workspace. For a more detailed overview of a specific package, please refer to the `README.md` file in the package's directory.

## `core`

The `core` package contains core functionality and utilities that are shared across multiple packages. This includes things like:

-   A logger
-   A dependency injection container
-   A set of utility functions

## `languist`

The `languist` package is responsible for managing localization and internationalization. It provides a set of tools for extracting and translating strings, as well as for formatting dates, numbers, and currencies.

## `shared`

The `shared` package contains shared domain models and business logic. This includes things like:

-   User models
-   Data transfer objects (DTOs)
-   Validation logic

## `ui_kit`

The `ui_kit` package contains a set of reusable UI components that are used throughout the application. This includes things like:

-   Buttons
-   Text fields
-   Modals
